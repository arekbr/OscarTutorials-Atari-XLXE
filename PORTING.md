# Porting OscarTutorials to Atari XL/XE

The port is based on [upstream revision a8ec725](https://github.com/drmortalwombat/OscarTutorials/tree/a8ec7255f53c8040c875c2058d76128707b8ce31).
Each lesson has a standalone XEX. The text, algorithms, and assets stay
as close as possible to the source. The registers, interrupts, and memory
layout target a stock XL/XE with 64 KiB of RAM. The upstream commit records
the starting point for the port.

## Verification

All 96 examples build with Oscar64 4f6df8b and `-tm=atari -O2`.
An independent rebuild produced byte-for-byte identical XEX files.
The build script checks the XEX segments and the linker map. The check
rejected a test binary whose code overlapped the startup routine at
`$2000`. The Atari assets can be regenerated byte for byte from
`Resources/`.

All examples were run in Atari800 5.2.0 with the 800XL rev. 2 OS ROM
in PAL and NTSC. Additional tests covered keyboard and joystick input,
graphics output, and POKEY register updates. Testing on a physical XL/XE
is pending.
